# One Touch Event Décor — v2 (Botanical Luxury)

A world-class, luxurious balloon & event decoration website for **One Touch Event Décor**.

Built with **Next.js 16**, **TypeScript**, **Tailwind CSS 4**, **shadcn/ui**, and **Framer Motion**.

## Highlights

- Cinematic loader intro — rising balloons + animated olive-branch logo reveal
- 15+ sections — hero, marquee, about, services, signature work, occasions, gallery, process, stats, testimonials, pricing, FAQ, contact, footer
- Botanical luxury palette — Deep Emerald + Blush Rose + Warm Cream + Copper + Charcoal (no blue, no gold)
- Premium interactions — cursor-follow glow, scroll progress bar, magnetic buttons, 3D tilt cards, floating contact menu
- Authentic backgrounds — animated mesh gradients, aurora glow, bokeh particles, grain texture, botanical line patterns
- Fully responsive — mobile-first, touch-friendly, sticky footer
- 21 AI-generated images in the exact brand palette
- Working booking form with API + success state + toast notifications
- Gallery with masonry layout + lightbox (keyboard accessible)

## Occasions covered

Weddings, Birthdays, Family Functions, Baby Showers, Corporate Events

## Local development

    cd v2
    bun install
    bun run dev

Open http://localhost:3000
