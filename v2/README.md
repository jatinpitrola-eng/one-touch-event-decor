# Velvet Bloom — Botanical Luxury Event Décor (v2)

A world-class, luxurious balloon & event decoration website for **Velvet Bloom**.

Built with Next.js 16, TypeScript, Tailwind CSS 4, shadcn/ui, and Framer Motion.

## Highlights
- Cinematic loader intro — rising balloons + animated wreath-and-bloom logo reveal
- 15+ sections with scroll animations
- Botanical luxury palette — Deep Emerald + Blush Rose + Warm Cream + Copper + Charcoal (no blue, no gold)
- Cursor-follow glow, scroll progress bar, magnetic buttons, 3D tilt cards, floating contact menu
- Authentic backgrounds — mesh gradients, aurora glow, bokeh, grain
- Responsive masonry gallery with keyboard-accessible lightbox
- Working booking form with API + success state + toast
- 21 AI-generated brand images
- Fully responsive, mobile-first, sticky footer

## Local development
    cd v2
    bun install
    bun run dev

Open http://localhost:3000
